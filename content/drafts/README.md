# Drafts

Writing posts in progress live here as `.mdx` files (same frontmatter as `content/writing/`).
Everything in this folder except this README is git-ignored, so drafts never get committed or pushed to the public repo.
Preview them with `npm run dev`; every file here is treated as `draft: true`.
The production build never includes them.
To publish: move the file to `content/writing/` (set `draft: false` or remove it), commit, push.
